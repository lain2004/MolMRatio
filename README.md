# MolMRatio
# 摩尔质量 · 元素质量计算器

一个零依赖的单文件网页程序：输入**物质总质量**与**各元素物质的量之比**，自动计算摩尔质量、各元素质量与质量分数。双击 `摩尔质量计算器.html` 即可在任意现代浏览器（Edge / Chrome 等）中打开使用，无需安装任何东西。

## 功能

- **化学式快捷填充**：直接输入化学式（如 `Ca(OH)2`、`CuSO4·5H2O`、`C6H12O6`），自动拆解为元素及比例
  - 支持括号（含中括号）嵌套、水合物 `·`、大小写容错（`h2o` → H₂O、`nacl` → NaCl）
  - 附常用物质快捷按钮
- **手动输入**：逐行添加元素 + 物质的量之比（支持小数比例），元素框支持下拉候选与中文名（如输"铁"→ Fe）
- **单位**：总质量支持 g / mg / kg，结果按所选单位显示
- **结果输出**：
  - 摩尔质量 M（g/mol）与物质的量 n（mol）
  - 各元素质量占比可视化条 + 图例
  - 明细表：原子量、个数比、各元素质量、质量分数（含合计行）
  - 可展开的逐步计算过程
  - 一键复制结果摘要
- **数据**：1–118 号元素完整周期表（符号 / 中文名 / 原子量）

## 计算原理

设物质由元素 E₁…Eₖ 按 E₁:E₂:…:Eₖ = ν₁:ν₂:…:νₖ 组成：

- 摩尔质量：M = Σ νᵢ·Mᵢ（Mᵢ 为元素 i 的原子量）
- 物质的量：n = m ÷ M
- 各元素质量：m(Eᵢ) = m × (νᵢ·Mᵢ) ÷ M
- 质量分数：wᵢ = (νᵢ·Mᵢ) ÷ M

其中 m 为物质总质量，νᵢ 为个数比。

## 数据来源

元素原子量采用 IUPAC 标准原子量常见教学取值；放射性 / 人工合成元素（Tc、Pm、Po 及 87 号以后）按最稳定同位素的质量数取值（如 Tc 97、Lr 262、Db 270 等）。
